🔍 Intro : Qu’est-ce que le Machine Learning (ML) ?

Le machine learning (ML) ou apprentissage automatique, regroupe des méthodes permettant d’apprendre des relations ou des structures à partir de données, notamment pour réaliser des prédictions sur de nouvelles observations.

Question de recherche Type de méthode associé
Peut-on prédire le prix de vente d’un appartement à partir de sa superficie, de sa localisation et du nombre de pièces ? Prédiction (régression)
Peut-on déterminer si un âne souffrant de coliques présente une infection à partir de sa température et de sa fréquence cardiaque ? Classification
Peut-on reconnaître le chiffre (de 0 à 9) représenté sur une image manuscrite ? Reconnaissance d’image (classification)
Peut-on identifier différents profils cliniques parmi les animaux hospitalisés dans un même CHUV à partir de leur bilan sanguin ? Classification non supervisée

Note

Il existe différentes méthodes de ML, dont le choix dépend de la question de recherche, de la nature des données et de l’objectif de l’analyse.

1️⃣ Pourquoi faire du Machine Learning ? - Intuition

Le machine learning est particulièrement intéressant pour :

  • Analyser des données complexes et de grande dimension : nombreuses variables, relations non linéaires et interactions.

    Exemple : prédire une maladie à partir de milliers de mesures génomiques.

  • Améliorer les performances prédictives : construire des modèles capables de prédire correctement de nouvelles observations.

    Exemple : prédire le risque de complications chez un cheval souffrant de coliques.

  • Exploiter des données non structurées : images, textes ou signaux.

    Exemple : détecter des anomalies sur des radiographies vétérinaires.

2️⃣ Définir le problème : Quelles sont les données ?

En apprentissage supervisé, on dispose d’un échantillon de \(n\) individus supposés i.i.d., pour lesquels on observe \(p\) variables explicatives et une variable réponse.

Matrice des variables explicatives

\[ X = \begin{pmatrix} x_{11} & \cdots & x_{1p} \\ \vdots & \ddots & \vdots \\ x_{n1} & \cdots & x_{np} \end{pmatrix} \]

Vecteur des réponses

\[ Y = \begin{pmatrix} y_1 \\ \vdots \\ y_n \end{pmatrix} \]

  • \(Y\) quantitatif : Régression

  • \(Y\) qualitatif : Classification

Objectif : à partir des couples observés \((x_i,y_i)\), apprendre une fonction de prédiction/ un modèle pour prédire la réponse d’un nouvel individu à partir de ses variables explicatives.

2️⃣ Choisir un modèle : Comment prédire \(Y\) ?

modèle de prédiction

En apprentissage supervisé, on choisit une famille de fonctions, de modèles de prédiction \(h_\theta\), paramétrés par \(\theta\), tels que : \[ h_\theta : x \longmapsto \hat y = h_\theta(x) \]

où \(\theta\) désigne les paramètres inconnus à estimer à partir des données.

Note

En pratique, le modèle de prédiction qu’on utilise dépend de la nature de la sortie et de l’objectif.

2️⃣ Entraîner le modèle : Comment estimer les paramètres ?

Objectif : Apprendre les paramètres ou les règles du modèle \(h_\theta\) à partir des observations \((x_i,y_i)\).

Principales approches :

Approche Principe mathématique (ex. de fonctions) Exemples
Minimisation d’une fonction de perte \(\displaystyle \hat\theta=\arg\min_{\theta\in\Theta}\sum_{i=1}^{n} (y_i - h_\theta(x_i))^2\) Régression linéaire, réseaux de neurones
Maximum de vraisemblance \(\displaystyle \hat\theta=\arg\max_{\theta\in\Theta}\prod_{i=1}^{n}\mathbb P_\theta(Y_i=y_i\mid X_i=x_i)\) Régression logistique
Construction successive de règles \(\text{Meilleure règle} = \text{celle qui sépare le mieux les deux classes}\) Arbres de décision, forêts aléatoires
Entraînement séquentiel de modèles \(h^{(m)}(x)=h^{(m-1)}(x)+\eta\,\operatorname{Correction}_m(x)\) Gradient boosting

Note

L’entraînement consiste à apprendre automatique un modèle à partir des données, mais la méthode utilisée dépend du modèle choisi.

3️⃣ Séparer les données : Comment organiser l’entraînement ?

Objectif : Évaluer la capacité du modèle à prédire de nouvelles observations.

1. Séparer les données : Diviser aléatoirement les observations en deux ensembles :

Ensemble Utilisation Exemple de répartition
Entraînement (train) Construire les arbres de la forêt \(80\%\)
Test (test) Évaluer les prédictions sur de nouvelles observations \(20\%\)

2. Prétraiter les données :

  • Entraînement : Traiter les valeurs manquantes (ex. imputation) et encoder les variables si nécessaire.

  • Test : Appliquer les mêmes transformations, en utilisant uniquement les informations calculées sur l’entraînement.

3️⃣ Application - Séparer les données

# 1. Sélectionner les variables
donnees <- donnees %>%
  dplyr::select(
    Rectal_temperature,
    Pulse,
    Respiratory_rate,
    Packed_cell_volume,
    Total_protein,
    surgical_lesion
  ) %>%
  filter(!is.na(surgical_lesion)) %>%
  mutate(surgical_lesion = factor(surgical_lesion))

# 2. Séparer les données (80 % / 20 %)
set.seed(123)

id_train <- donnees %>%
  mutate(id = row_number()) %>%
  group_by(surgical_lesion) %>%
  slice_sample(prop = 0.8) %>%
  ungroup() %>%
  pull(id)

train <- donnees[id_train, ]
test <- donnees[-id_train, ]

# 3. Imputer les valeurs manquantes
variables <- setdiff(names(train), "surgical_lesion")

med <- sapply(train[variables], median, na.rm = TRUE)

for (v in variables) {
  train[[v]][is.na(train[[v]])] <- med[v]
  test[[v]][is.na(test[[v]])] <- med[v]
}

3️⃣ Entraîner le modèle : Comment construire la forêt en pratique ?

Objectif : Construire une forêt aléatoire à partir des données d’entraînement.

Méthode utilisée :

  • Échantillonnage bootstrap : tirer aléatoirement des observations pour chaque arbre.
  • Construction des arbres : rechercher à chaque nœud la meilleure séparation parmi un sous-ensemble aléatoire de variables.
  • Répétition : construire plusieurs arbres pour constituer la forêt.

Note

Dans R, la fonction ranger() construit automatiquement la forêt aléatoire. Les prédictions en classification sont obtenues par vote majoritaire.

3️⃣ Validation croisée : Comment optimiser les performances ?

Objectif : Évaluer la capacité du modèle à prédire de nouvelles observations et, si nécessaire, sélectionner les meilleurs hyperparamètres.

Principe : Validation croisée à \(K\) blocs

  1. Diviser les données d’entraînement en \(K\) blocs.

  2. Entraîner la forêt sur \(K-1\) blocs et évaluer les prédictions sur le bloc restant.

  3. Répéter l’opération \(K\) fois, en changeant le bloc utilisé pour l’évaluation.

  4. Calculer la performance moyenne obtenue sur les \(K\) blocs.

Note

On réalise une validation croisée à \(K=5\) blocs pour comparer différentes valeurs de mtry et retenir celle qui maximise l’accuracy moyenne.

3️⃣ Application - Validation croisée

# Données avant imputation
train_cv <- donnees[id_train, ]

variables <- setdiff(
  names(train_cv), "surgical_lesion"
)

# Création de 5 blocs
set.seed(123)
K <- 5
blocs <- sample(rep(
  1:K, length.out = nrow(train_cv)
))

# Comparer différentes valeurs de mtry
mtry_test <- 1:length(variables)

accuracy <- sapply(mtry_test, function(mtry) {

  mean(sapply(1:K, function(k) {

    app <- train_cv[blocs != k, ]
    val <- train_cv[blocs == k, ]

    # Imputation
    med <- sapply(app[variables],
                  median, na.rm = TRUE)

    for (v in variables) {
      app[[v]][is.na(app[[v]])] <- med[v]
      val[[v]][is.na(val[[v]])] <- med[v]
    }

    # Entraînement
    m <- ranger(
      surgical_lesion ~ .,
      data = app,
      num.trees = 500,
      mtry = mtry,
      seed = 123 + k
    )

    # Prédiction et accuracy
    pred <- predict(m, data = val)$predictions
    mean(pred == val$surgical_lesion)

  }))
})

# Sélection du meilleur mtry
mtry_opt <- mtry_test[which.max(accuracy)]

round(accuracy, 3)
mtry_opt

3️⃣ Évaluer le modèle : Comment mesurer la qualité des prédictions ?

Principe : Comparer les classes prédites \(\hat y_i\) aux réponses observées \(y_i\) sur le jeu de test, à l’aide d’une matrice de confusion.

Prédit : Lésion (\(\hat Y=1\)) Prédit : Pas de lésion (\(\hat Y=0\))
Observé : Lésion (\(Y=1\)) Vrai positif (VP) Faux négatif (FN)
Observé : Pas de lésion (\(Y=0\)) Faux positif (FP) Vrai négatif (VN)

Indicateurs de performance :

Indicateur Formule Interprétation
Accuracy \(\dfrac{VP+VN}{VP+VN+FP+FN}\) Proportion de prédictions correctes
Sensibilité \(\dfrac{VP}{VP+FN}\) Proportion de lésions détectées
Spécificité \(\dfrac{VN}{VN+FP}\) Proportion d’absences de lésion correctement identifiées

3️⃣ Application - Évaluer le modèle

# Entraîner avec le meilleur mtry
modele <- ranger(
  surgical_lesion ~ .,
  data = train,
  num.trees = 500,
  mtry = mtry_opt,
  seed = 123
)

# Prédictions sur le jeu de test
pred <- predict(
  modele, data = test
)$predictions

# Matrice de confusion
conf <- table(
  Observe = factor(test$surgical_lesion,
                   levels = c("Oui", "Non")),
  Predit = factor(pred,
                  levels = c("Oui", "Non"))
)

VN <- conf["Non", "Non"]
FP <- conf["Non", "Oui"]
FN <- conf["Oui", "Non"]
VP <- conf["Oui", "Oui"]

# Indicateurs de performance
df <- data.frame(
  Indicateur = c("Accuracy", "Sensibilité",
                 "Spécificité"),
  Valeur = round(c(
    (VP + VN) / sum(conf),
    VP / (VP + FN),
    VN / (VN + FP)
  ), 3)
)

📑 Exemple d’utilisation en sciences vétérinaires

Exemple issu de : Macleod et al. (2025)

Note

Dans cet article, une forêt aléatoire est utilisée pour prédire la survie de 57 chevaux présentant des coliques, à partir de données cliniques et sanguines.

Avec une sensibilité de 90,9 % et une spécificité de 83,3 %, la forêt aléatoire identifie correctement la majorité des chevaux qui survivront et de ceux qui décéderont.

🎯 Conclusion


A retenir (5 étapes pour construire et évaluer la qualité d’un modèle) :

  1. Préparer les données : sélectionner les variables et vérifier leur qualité.
  2. Séparer les données : entraînement et test.
  3. Entraîner le modèle : estimer ses paramètres.
  4. Effectuer une validation croisée : évaluer les performances et ajuster les hyperparamètres si nécessaire.
  5. Évaluer le modèle : mesurer les performances sur les données de test.
